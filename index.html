01 / THE BIG PICTURE

One image. Four decisions.
Multiple ways to mislead.

Typed decision models return structured answers rather than free-form text. VisualJevBench evaluates how direct image manipulations affect binary verification, option selection, scoring, and localization.

Abstract / research overview

We introduce VisualJevBench, a benchmark comprising 800 images and 3,200 questions across eight scenarios. It covers four visual attack surfaces: typographic manipulation, visual evidence spoofing, target selection interference, and geometric transformation. Adaptive Black-Box Parameter Search (ABPS) uses typed-output feedback to search for effective manipulations, both for individual images and for universal configurations applied to unseen images and new scenarios without further optimization.

03 / METHOD

ABPS: search with typed feedback.

Adaptive Black-Box Parameter Search optimizes image manipulation parameters using model responses, without requiring gradients or internal model access.

  1. Propose

    Select an attack surface and manipulation parameters.

  2. Render & query

    Apply the manipulation and obtain a typed decision.

  3. Evaluate & update

    Use typed-output feedback to guide subsequent proposals.

Image-specific search

Search for effective configurations for individual inputs.

Universal search

Select configurations on training images, freeze them, and apply them to held-out images and new scenarios without further optimization.

What counts as success?

ASR measures the proportion of clean-correct instances where a valid image manipulation induces an incorrect decision. Correctness is evaluated by question type; attacks are evaluated under answer-preserving constraints. See the paper for eligibility, thresholds, and aggregation details.
